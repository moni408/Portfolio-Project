This is my personal portfolio website, showcasing my projects, skills, and contact information.  
It is built with **HTML, CSS, and JavaScript** and is fully responsive.

## Features

- Home page with introduction and **“Download CV”** button
- About section highlighting my background and skills
- Projects section showcasing my work
- Contact section with social links and email
- Clean and responsive design for all devices
